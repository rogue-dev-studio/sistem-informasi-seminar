# Sistem Informasi Seminar

Aplikasi Android (Java) untuk layar login seminar informatika. Ini prototipe kuliah, bukan sistem seminar lengkap dan bukan proyek App Inventor / PHP / MySQL.

## Stack

- Java
- Android (AppCompat / Gradle)
- Android Studio module: `Login`

## Menjalankan

Buka folder `Login/` di Android Studio, sync Gradle, jalankan di emulator atau perangkat.

## Batasan

- Hanya alur login ke layar berikutnya
- Tidak ada backend, daftar seminar, atau basis data
- Package masih `com.example.maninback.login` (nama modul latihan)
